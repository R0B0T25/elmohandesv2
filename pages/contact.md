           في انتظار ذلك، يمكنك استعراض مشاريعنا."

## ملاحظات المطور

- الفورم يُرسَل بـ Fetch API — بدون page reload
- Validation يعمل inline (عند blur من الحقل)
- File upload: preview للصور قبل الإرسال
- الـ Success state يظهر بـ animation (opacity + translateY)
- WhatsApp link يفتح `wa.me/201XXXXXXXXX?text=مرحباً، أريد الاستفسار عن...`
