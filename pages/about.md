## المشاهد (Scenes)

### 🎬 Scene 01 — Hero
```

الخلفية: صورة للفريق أو لمشروع مميز

```

### 🎬 Scene 02 — القصة (Story)
```
Layout: Editorial — نص كبير + صورة جانبية
الخلفية: --color-ivory

[H2]    — "القصة التي بدأت بسؤال"
[Body]  — "في 2015، انطلقنا بسؤال بسيط:
           لماذا التشطيب الجيد نادر في مصر؟
           
           الإجابة كانت في التفاصيل.
           في الالتزام.
           في الحرص على كل ملليمتر.
           
           منذ ذلك اليوم، هذا ما نفعله."

الصورة: مشهد من داخل أحد المشاريع الأولى أو الحالية
```

### 🎬 Scene 04 — القيم الأساسية
```
Layout: 3 Values — غير متكررة البنية
الخلفية: --color-ivory

[H2]    — "ما الذي يُميّزنا"

القيم:
  [الحرفية]         — صورة تفصيل + نص
  [الشفافية]        — رقم أو مثال + نص
  [الاهتمام بالوقت] — timeline صغير + نص

ليس بطاقات مكررة — كل قيمة لها أسلوب عرض مختلف
```

---

### 🎬 Scene 05 — الفريق
```
Layout: Editorial Grid — ليس 3 صفوف متكررة
الخلفية: --color-white

[H2]    — "الفريق وراء كل مشروع"
[Body]  — "مهندسون وحرفيون يؤمنون بأن التفصيل فن."

بطاقات الفريق:
  صورة (portrait طبيعية — لا corporate poses)
  الاسم + الدور
  جملة واحدة مميزة

عدد مناسب — لا تكثر
```
